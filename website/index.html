Chess with a time machine

Every rewind opens a new timeline.

RewindChess is a two-player chess game where you can go back to an earlier position and try another move. The original game is never lost, so you can compare both outcomes.

The core mechanic

How a rewind works

  1. 1. Look back

    Open any earlier position or timeline. Looking is free and read-only.

  2. 2. Continue from here

    Choose to play on from that position. This uses one rewind.

  3. 3. A new timeline

    Your new moves go into a new branch. The old game is still there.
