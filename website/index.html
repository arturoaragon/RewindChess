RewindChess

Chess with a time machine.

RewindChess is a two-player chess game where you can go back to an earlier position and try another move. The original game is never lost, so you can compare both outcomes.

How to play · Download

Overview

  • Chess for two players on one computer, with the normal chess rules.
  • Rewinds: look at any earlier position for free, or continue from it in a new timeline. The old game stays as it was.
  • Three game modes with a different number of rewinds per player: Practice, Competitive and Competitive + Abilities.
  • Special abilities: in one mode, each player gets one surprise move per game.

RewindChess is a desktop game for Windows, written in C++. It is being built step by step between October and December 2026, so these features are added during the project.
